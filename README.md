# Task Management Web Application

A responsive, client-side To-Do List and Task Management application built with vanilla HTML5, CSS3, and JavaScript. Designed as a collaborative duo project using a structured Git & GitHub feature-branch workflow.

---

## Features

- **Core Task Management (CRUD):** Add, view, edit, toggle completion, and delete tasks dynamically.
- **Persistent Storage:** Automatically saves and loads tasks using the browser's `localStorage` so data persists across page reloads.
- **Task Counter & Statistics:** Displays real-time counts of total, active, and completed tasks.
- **Bulk Actions:** One-click option to clear all completed tasks from the list.
- **Search & Status Filtering:** Quickly locate tasks or filter views by status (All, Active, Completed).
- **Responsive Design:** Clean, structured interface styled with modern CSS3 for desktop and mobile viewports.

---

## Tech Stack

- **Frontend:** HTML5, CSS3, Vanilla JavaScript (ES6+)
- **Storage:** Web Storage API (`localStorage`)
- **Version Control & Collaboration:** Git, GitHub (Feature Branches & Pull Requests)
